# Unit 013 — Quiz: Bash Commands Quiz (Q)
- URL: https://www.freecodecamp.org/learn/relational-databases-v9/quiz-bash-commands/quiz-bash-commands
- Format: 20Q × 4 options, pass ≥18/20, control "Finish the quiz". NOTE: option order SHUFFLES per load ⇒ key by option TEXT only.
- Verbatim set (signed-in capture 2026-11-01, this load's order):
1. What command is used to see the path of the working directory? — cd / mv / ls / pwd
2. Which command is used to see what is present in a file? — mv / ls / touch / cat
3. Which command is used to create a new file? — mkdir / touch / ls / cd
4. Which command is used to remove a file? — mv / rm / cp / cd
5. Which command is used to copy a particular file to a folder? — cd <file> <destination> / rm <file> <destination> / mv <file> <destination> / cp <file> <destination>
6. Which command lists the files and folders in a directory? — mv / ls -l / ls / touch
7. Which command will rename the 'menlo.font' file to 'menlo.otf'? — mv menlo.font menlo.otf / cp menlo.font menlo.otf / rm menlo.font menlo.otf / ls menlo.font menlo.otf
8. Which command can be used to find files or view a file tree? — mv / rm / find / ls
9. Which command is used to make a directory? — mv / dir / touch / mkdir
10. Which command would print the text I finished the example quiz? — cp … / ls … / cd … / echo I finished the example quiz
11. Which command would you use if you want to add text to a file directly from the terminal? — ls <text> >> <filename> / mv <text> >> <filename> / echo <text> >> <filename> / cp <text> >> <filename>
12. Which command is used to remove directories and their content recursively? — rm -r / dir -r / cp -r / cd -r
13. Which command is used to remove a protected file? — rm / rm -r / rm --help / rm -f
14. Which command is used to go back to the parent directory? — mv .. / dir .. / cd .. / cp ..
15. Which flag can be used for any command to get a help menu? — --help / --info / -l / --r
16. Which keybind is used to stop a running process? — Ctrl + L / Ctrl + C / Shift + C / Alt + C
17. Which keybind is used to clear the terminal? — Shift + L / Ctrl + L / Ctrl + C / Alt + L
18. Which command is used to copy the whole folder? — mv -r <folder_to_copy> <name_of_copy> / dir -r … / cp -r <folder_to_copy> <name_of_copy> / cd -r …
19. Which flag is used with ls to include hidden files and folders? — -r / -rf / -a / -l
20. Which flag is used with the ls command to include additional information, such as the permissions? — ls --help / ls -f / ls -rf / ls -l
