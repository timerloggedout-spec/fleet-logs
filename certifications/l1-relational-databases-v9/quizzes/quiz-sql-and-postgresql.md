## Verbatim set (signed-in capture 2026-11-01, this load's order)
1. What does SQL stand for? — Structured Query Language / Standard Query Language / Sequential Query Language / Simple Query Language
2. Which SQL data type is used to store text data? — TEXT / VARCHAR / CHAR / STRING
3. What does the \l command do in psql? — Lists all databases / Lists all tables in the current database / Lists all users / Exits psql
4. What is the purpose of a primary key in a relational database? — To ensure that all records in a table are unique / To allow duplicate records / To store large amounts of data / To link tables together
5. Which SQL clause is used to filter records based on a condition? — GROUP BY / HAVING / ORDER BY / WHERE
6. Which SQL command is used to add a new record to a table? — ADD / INSERT INTO / CREATE / UPDATE
7. What type of relationship exists when one record in Table A corresponds to one or more records in Table B, and each record in Table B corresponds to at most one record in Table A? — One-to-one / One-to-many / Many-to-one / Many-to-many
8. Which SQL command is used to modify existing data in a table? — DELETE / INSERT / CREATE / UPDATE
9. Which SQL command is used to create a new table? — CREATE TABLE / INSERT TABLE / NEW TABLE / ADD TABLE
10. Which SQL JOIN returns all rows from both tables, including unmatched rows? — RIGHT JOIN / LEFT JOIN / INNER JOIN / FULL OUTER JOIN
11. What does the command \c do in psql? — Connects to a specified database / Creates a new database / Lists all databases / Exits psql
12. Which SQL statement is used to retrieve data from a database? — GET / SELECT / FETCH / RETRIEVE
13. What is the purpose of a foreign key in a relational database? — To ensure data integrity by linking tables / To store large amounts of data / To uniquely identify each record in a table / To speed up query performance
14. Which of the following is NOT a valid SQL data type? — VARCHAR / TEXT / INTEGER / STRING
15. Which SQL command is used to delete a record from a table? — DROP / DELETE / REMOVE / TRUNCATE
16. Which SQL constraint specifically ensures that a column can contain only unique values, allowing nulls? — PRIMARY KEY / NOT NULL / UNIQUE / FOREIGN KEY
17. Which of the following is a valid SQL statement to create a database? — CREATE DATABASE mydb; / NEW DATABASE mydb; / MAKE DATABASE mydb; / ADD DATABASE mydb;
18. Which SQL JOIN returns only the rows with matching values in both tables? — RIGHT JOIN / LEFT JOIN / FULL OUTER JOIN / INNER JOIN
19. Which SQL command is used to change the structure of an existing table? — ALTER TABLE / MODIFY TABLE / UPDATE TABLE / CHANGE TABLE
20. Which of the following best describes a relational database? — A database that stores data in a single file / A database that uses tables to organize data and relationships / A database that only stores text data / A database that doesn't use SQL
