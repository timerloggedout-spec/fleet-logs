## Answers to FreeCodeCamp Relational Databases v9 Lesson: GitHub Pages Deployment

**KEY Q1:** A static website and a GitHub repository

**Q1: What are the two main components involved in deploying a project using GitHub Pages?**

**A:** A static website and a GitHub repository

**Justification:**  GitHub Pages is specifically designed for hosting static websites directly from a GitHub repository.

**Evidence:** *"GitHub Pages hosts your website directly from a GitHub repository..."*

**KEY Q2:** https://johndoe.github.io/my-portfolio/

**Q2: If your GitHub username is johndoe and your repository is named my-portfolio, what URL would your GitHub Pages site be deployed to?**

**A:** https://johndoe.github.io/my-portfolio/

**Justification:** The URL structure follows the pattern `username.github.io/repository-name`.

**Evidence:** *"...your site will be accessible at https://your-username.github.io/your-repository-name/."*

**KEY Q3:** Deploy your site using a predefined workflow

**Q3: What does enabling GitHub Actions in the Pages settings allow you to do?**

**A:** Deploy your site using a predefined workflow

**Justification:** GitHub Actions automates tasks including deployment, and the lesson mentions predefined workflows.

**Evidence:** *"...you can enable GitHub Actions in the Pages settings to automate the deployment process using predefined workflows."*
