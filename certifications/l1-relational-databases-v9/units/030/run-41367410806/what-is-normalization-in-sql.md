Q1: What is the main purpose of normalization in a database?
A) Reducing data redundancy and improving data integrity.
Normalization aims to eliminate redundant data and ensure data integrity by organizing data into well-structured tables.
Lesson evidence: "Normalization is the process of organizing data in a database to reduce data redundancy and improve data integrity."

Q2: Which normal form addresses partial dependencies, where non-key attributes depend on only part of a composite key?
B) Second Normal Form (2NF)
Second Normal Form addresses partial dependencies by ensuring non-key attributes depend on the entire primary key.
Lesson evidence: "Second Normal Form (2NF) addresses partial dependencies, where non-key attributes depend on only part of a composite key."

Q3: Which normal form addresses transitive dependencies, where a non-key attribute depends on another non-key attribute?
C) Third Normal Form (3NF)
Third Normal Form addresses transitive dependencies by ensuring non-key attributes depend only on the primary key.
Lesson evidence: "Third Normal Form (3NF) addresses transitive dependencies, where a non-key attribute depends on another non-key attribute."
