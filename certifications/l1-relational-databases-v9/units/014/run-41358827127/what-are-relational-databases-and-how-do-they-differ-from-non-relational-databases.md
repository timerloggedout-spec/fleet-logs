# FreeCodeCamp Relational Databases v9 Lesson Answers

## Q1: Which of the following is a key characteristic of relational databases?

**Correct Option: Structured data in tables**

*Justification:* Relational databases are defined by their use of tables to organize data into rows and columns, creating structured relationships.

*Evidence:* "Relational databases ... organize data into tables with rows and columns."

KEY Q1: Structured data in tables

## Q2: Which of the following statements is true about relational databases?

**Correct Option: They require a predefined schema.**

*Justification:* The lesson emphasizes that relational databases need a schema designed in advance to define the structure of the data.

*Evidence:* "Relational databases require a predefined schema that defines the structure of the data."

KEY Q2: They require a predefined schema.

## Q3: Which of the following statements is true about non-relational databases?

**Correct Option: They allow for more flexible data modeling.**

*Justification:* The lesson describes non-relational databases as offering flexibility in data structure, contrasting with the rigid schema of relational databases.

*Evidence:* "Non-relational databases ... allow for more flexible data modeling."

KEY Q3: They allow for more flexible data modeling.
