# Q1: Which data type is used to store whole numbers in PostgreSQL?

**Correct option:** INTEGER

**Justification:** The INTEGER data type is designed for whole numbers, which are numbers without decimal points.

**Evidence:** "The INTEGER data type is used to store whole numbers."

KEY Q1: INTEGER

# Q2: If you need to store a long text document or a very long string, which data type should you use in PostgreSQL?

**Correct option:** TEXT

**Justification:** The TEXT data type is suitable for storing large amounts of text or long strings.

**Evidence:** "The TEXT data type is used to store large strings or documents."

KEY Q2: TEXT

# Q3: Which data type would you use to store a TRUE or FALSE value in a PostgreSQL database?

**Correct option:** BOOLEAN

**Justification:** The BOOLEAN data type is specifically created to hold binary values, such as TRUE or FALSE.

**Evidence:** "The BOOLEAN data type is used to store binary values, such as TRUE or FALSE."

KEY Q3: BOOLEAN
