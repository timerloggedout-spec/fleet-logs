## Answers to FreeCodeCamp Relational Databases v9 Lesson: "What Is a Repository, and How Do You Create One?"

**KEY Q1:** A container for a project and its files.

**Q1:** What does a repository primarily function as in Git?

**A:**  A container for a project and its files.

**Justification:**  The lesson states: "A Git repository is a container for your project and all its files."

**Evidence:**  "A Git repository is a container for your project and all its files. It allows you to track changes to your project over time, collaborate with others, and easily revert to previous versions if needed."

**KEY Q2:** A package.json file.

**Q2:** When creating a repository on GitHub, which of the following is NOT an automatic file generation option?

**A:** A package.json file.

**Justification:** The lesson lists README, .gitignore, and license files as automatic file generations, but not package.json.

**Evidence:**  "When you create a new repository on GitHub, it will automatically generate a README file, a .gitignore file, and a license file to help you get started."

**KEY Q3:** git clone

**Q3:** Which of the following Git commands is used to clone a remote repository to your local computer?

**A:** git clone

**Justification:** The lesson explicitly states the `git clone` command is used for this purpose.

**Evidence:** "To get a copy of a remote repository on your local computer, you use the `git clone` command."
