# Answers to FreeCodeCamp Relational Databases v9 Lesson: Keyboard Shortcuts for VS Code

## Q1: What is the Windows shortcut to run the formatter on the current file?

**Correct Option:** Shift+Alt+F

**Justification:** The lesson specifies "format Shift+Alt+F" for Windows and Linux, indicating that this shortcut runs the formatter on the current file.

**Evidence:** "App-specific shortcuts (Win/Linux | macOS): format Shift+Alt+F | Shift+Option+F;"

## Q2: What does Ctrl+Shift+K do on Windows and Linux?

**Correct Option:** it deletes the current line

**Justification:** The provided list includes "delete line Ctrl+Shift+K", directly stating the function of this shortcut.

**Evidence:** "App-specific shortcuts (Win/Linux | macOS): ... delete line Ctrl+Shift+K;"

## Q3: Which shortcut opens the command palette?

**Correct Option:** Ctrl+Shift+P

**Justification:** Both Windows/Linux and macOS instructions list "command palette Ctrl+Shift+P | Cmd+Shift+P", making it the correct choice.

**Evidence:** "App-specific shortcuts (Win/Linux | macOS): ... command palette Ctrl+Shift+P | Cmd+Shift+P."
