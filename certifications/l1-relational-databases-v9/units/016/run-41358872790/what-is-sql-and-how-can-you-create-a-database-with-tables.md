# Answers to FreeCodeCamp Relational Databases v9 Lesson

## Q1: What does the acronym SQL stand for?

**Correct Option:** Structured Query Language

**Justification:** SQL is an acronym that stands for Structured Query Language, as introduced in the lesson.

**Evidence:** "SQL (Structured Query Language) is a standard language for managing and manipulating relational databases."

KEY Q1: Structured Query Language

## Q2: What is SQL primarily used for?

**Correct Option:** Managing relational databases.

**Justification:** The lesson emphasizes that SQL is used for interacting with relational databases, including creating, managing, and manipulating data within them.

**Evidence:** "SQL (Structured Query Language) is a standard language for managing and manipulating relational databases."

KEY Q2: Managing relational databases.

## Q3: What is a relational database?

**Correct Option:** A database that stores data in tables.

**Justification:** The lesson defines a relational database as a type of database that organizes data into tables with rows and columns.

**Evidence:** "A relational database is a type of database that stores data in tables. Each table has columns (vertical) and rows (horizontal)."

KEY Q3: A database that stores data in tables.
