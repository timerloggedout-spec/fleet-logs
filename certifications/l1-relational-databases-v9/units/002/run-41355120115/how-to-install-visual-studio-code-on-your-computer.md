# Answers to FreeCodeCamp's "How to Install Visual Studio Code" Lesson

## Q1: What's an important distinction to make when downloading Visual Studio Code?

**Correct Option:** **download from the VS Code website, not the Visual Studio website**

**Justification:** The lesson explicitly states, "Download VS Code from the VS Code website - NOT the Visual Studio website (key distinction)."

**Evidence:** "Download VS Code from the VS Code website - NOT the Visual Studio website (key distinction)."

## Q2: Which is NOT mentioned as a method to install VS Code on macOS?

**Correct Option:** **downloading a .app file**

**Justification:**  The lesson lists three methods for macOS: ".zip with .app, or Homebrew `brew install --cask visual-studio-code`." Downloading a standalone `.app` file is not explicitly mentioned.

**Evidence:** "Mac: .zip with .app, or Homebrew `brew install --cask visual-studio-code`."
