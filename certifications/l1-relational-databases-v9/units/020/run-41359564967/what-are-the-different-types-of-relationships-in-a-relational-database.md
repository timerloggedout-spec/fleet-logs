## Answers to FreeCodeCamp Relational Databases v9 Lesson

**KEY Q1:** One-to-many

**Q1: In which type of relationship can one record in Table A be associated with zero, one, or many records in Table B, while each record in Table B can be associated with only one record in Table A?**

**Correct Option:** One-to-many

**Justification:** A one-to-many relationship allows for one record in Table A to be linked to multiple records in Table B, but each record in Table B can only be associated with one record in Table A.

**Evidence:**  *"One-to-many relationships are the most common type of relationship in relational databases. In this type of relationship, one record in Table A can be associated with zero, one, or many records in Table B, while each record in Table B can be associated with only one record in Table A."*

**KEY Q2:** A relationship where multiple rows in one table are related to multiple rows in another table.

**Q2: What is a many-to-many relationship in a relational database?**

**Correct Option:** A relationship where multiple rows in one table are related to multiple rows in another table.

**Justification:**  A many-to-many relationship signifies that numerous records in one table are associated with numerous records in another table.

**Evidence:** *"Many-to-many relationships occur when multiple rows in one table are related to multiple rows in another table."*

**KEY Q3:** Self-referencing

**Q3: Which type of relationship involves records within the same table being linked to other records in that same table?**

**Correct Option:** Self-referencing

**Justification:** Self-referencing relationships involve records within a single table referencing other records within the **same** table.

**Evidence:** *"Self-referencing relationships involve records within the same table being linked to other records in that same table."*
