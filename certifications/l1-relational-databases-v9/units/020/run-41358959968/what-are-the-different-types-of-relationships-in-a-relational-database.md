# FreeCodeCamp Relational Databases v9 Lesson: "What Are the Different Types of Relationships in a Relational Database?"

## Q1: In which type of relationship can one record in Table A be associated with zero, one, or many records in Table B, while each record in Table B can be associated with only one record in Table A?

**Correct Option:** One-to-many

**Justification:** A one-to-many relationship allows for one record in Table A to be linked to multiple records in Table B, but each record in Table B can only be associated with one record in Table A.

**Evidence from the lesson:** "In a one-to-many relationship, one record in Table A can be associated with zero, one, or many records in Table B, but each record in Table B can be associated with only one record in Table A."

KEY Q1: One-to-many

## Q2: What is a many-to-many relationship in a relational database?

**Correct Option:** A relationship where multiple rows in one table are related to multiple rows in another table.
