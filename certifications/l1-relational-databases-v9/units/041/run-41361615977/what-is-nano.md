## Answers to FreeCodeCamp Relational Databases v9 Lesson: What Is Nano?

**KEY Q1:** It's more user-friendly with on-screen keyboard shortcuts.

**Q1: What makes Nano different from editors like Vim and Emacs? **

**Correct Option:** It's more user-friendly with on-screen keyboard shortcuts.

**Justification:** Nano is described as having a "simpler interface" and displaying "on-screen help" which contributes to its user-friendliness.

**Evidence:**  "Nano is a text editor designed for simplicity. It’s similar to Vim and Emacs, but it has a simpler interface...Nano also displays on-screen help, which can be very helpful for beginners."

**KEY Q2:** Press the Control ( Ctrl ) key and the indicated letter.

**Q2: In Nano's interface, what does the caret (^) symbol before a key indicate?**

**Correct Option:** Press the Control ( Ctrl ) key and the indicated letter.

**Justification:** The lesson explicitly states that the caret symbol represents the Control key.

**Evidence:**  "In Nano, you’ll see a caret (^) symbol before some keys. This means to press the Control (Ctrl) key and the indicated letter."

**KEY Q3:** Ctrl + X

**Q3: What keyboard shortcut is used to save changes to a file in Nano?**

**Correct Option:** Ctrl + X

**Justification:** The lesson specifies that Ctrl + X is used to exit Nano, saving changes automatically.

**Evidence:** "To save your changes and exit Nano, press Ctrl + X."
