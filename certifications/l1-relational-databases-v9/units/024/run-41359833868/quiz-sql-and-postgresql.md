Q2: Which SQL data type is used to store text data?

KEY Q3: Lists all databases

Q4: What is the purpose of a primary key in a relational database?
KEY Q4: To ensure that all records in a table are unique

Q5: Which SQL clause is used to filter records based on a condition?
KEY Q5: WHERE

Q6: Which SQL command is used to add a new record to a table?
KEY Q6: INSERT INTO

Q7: What type of relationship exists when one record in Table A corresponds to one or more records in Table B, and each record in Table B corresponds to at most one record in Table A?
KEY Q7: One-to-many

Q8: Which SQL command is used to modify existing data in a table?
KEY Q8: UPDATE

Q9: Which SQL command is used to create a new table?
KEY Q9: CREATE TABLE

Q10: Which SQL JOIN returns all rows from both tables, including unmatched rows?
KEY Q10: FULL OUTER JOIN

Q11: What does the command \c do in psql?
KEY Q11: Connects to a specified database

Q12: Which SQL statement is used to retrieve data from a database?
KEY Q12: SELECT

Q13: What is the purpose of a foreign key in a relational database?
KEY Q13: To ensure data integrity by linking tables

Q14: Which of the following is NOT a valid SQL data type?

Q15: Which SQL command is used to delete a record from a table?
KEY Q15: DELETE

KEY Q16: UNIQUE

KEY Q17: CREATE DATABASE mydb;

KEY Q18: INNER JOIN
