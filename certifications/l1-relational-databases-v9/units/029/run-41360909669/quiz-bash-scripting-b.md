Q1: **#!/bin/bash**; Specifies the interpreter to execute the script.
KEY Q1: **#!/bin/bash**

Q2: **MY_VAR=10; echo $MY_VAR**; Assigns a value to the variable and then prints it.
KEY Q2: **MY_VAR=10; echo $MY_VAR**

Q3: **declare -p**; Displays all shell variables with their values and attributes.
KEY Q3: **declare -p**

Q4: **./script.sh**; Executes the script using the specified interpreter.
KEY Q4: **./script.sh**

Q5: **man less**; Displays the manual page for the `less` command.
KEY Q5: **man less**

Q6: **print_arguments "a" "b"**; Calls the function with the specified arguments.
KEY Q6: **print_arguments "a" "b"**

Q7: **ARR=("item1" "item2" "item3")**; Initializes an array with the given values.
KEY Q7: **ARR=("item1" "item2" "item3")**

Q8: **echo ${ARR[2]}**; Accesses and prints the third element of the array (index starts at 0).
KEY Q8: **echo ${ARR[2]}**

Q9: **read MY_VAR**; Reads a line from the standard input and assigns it to the variable.
KEY Q9: **read MY_VAR**

KEY Q10: **rwxrw-r-x**

Q11: **fi**; Marks the end of an `if` statement block.
KEY Q11: **fi**

Q12: **done**; Terminates a `for` or `while` loop.
KEY Q12: **done**

Q13: **# comment**; Adds a comment that is ignored by the interpreter.

Q14: **for (( i = 0; i < 10; i++ ));**; Creates a `for` loop with an initialization, condition, and increment.
KEY Q14: **for (( i = 0; i < 10; i++ ));**

Q15: **$C=$(( $A + $B ))**; Performs arithmetic and assigns the sum to variable C.

KEY Q16: **touch**

KEY Q17: **Prints the exit code of the last executed command.**

KEY Q18: **Script sections can be pasted directly into the terminal for testing.**

KEY Q19: **for, while, until**
