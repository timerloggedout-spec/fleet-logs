## Q1: What does VS Code consider a workspace?

**Correct Option:** the directory you opened in VS Code

**Justification:** A workspace in VS Code is simply the directory (folder) that you have opened in the application.

**Evidence:** "...VS Code project = "workspace" = the directory opened..."

## Q2: Why might you use a web server instead of opening an HTML file directly in the browser?

**Correct Option:** it avoids unexpected bugs such as CSS not loading

**Justification:** Using a local web server helps prevent issues like CSS files not loading correctly when opening HTML files directly.

**Evidence:** "...Serve with Live Server extension (Go Live, http://localhost:5500/) instead of opening the file directly (avoids CSS loading bugs)."
