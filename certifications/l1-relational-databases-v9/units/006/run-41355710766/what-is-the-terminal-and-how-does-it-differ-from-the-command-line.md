# FreeCodeCamp Relational Databases v9 Lesson: "What Is the Terminal, and How Does It Differ from the Command Line?"

## Q1: What is a terminal?

**Correct Option:** a special application that offers a command-line interface for system-level commands

**Justification:** A terminal is a software application that provides a text-based interface for users to interact with the operating system, allowing them to execute commands and access system functionality.

**Lesson Evidence:** "A terminal is a special application that offers a command-line interface for system-level commands."

## Q2: What is a shell?

**Correct Option:** software that wraps the command-line interface and interprets user inputs

**Justification:** A shell is a program that takes commands from the user and gives them to the operating system for processing, acting as an intermediary between the user and the system.

**Lesson Evidence:** "A shell is software that wraps the command-line interface and interprets user inputs."

## Q3: What is an advantage of Windows Terminal?

**Correct Option:** it lets you use PowerShell and Command Prompt in the same app

**Justification:** Windows Terminal combines the functionality of PowerShell and Command Prompt, allowing users to work with both in a single application.
