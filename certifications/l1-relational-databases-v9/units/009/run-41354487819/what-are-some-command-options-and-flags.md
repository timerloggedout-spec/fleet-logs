## Q1: What prefix marks the long form of a command option?

**Correct Option:** -- (two dashes)

**Justification:** The lesson content explicitly states that long-form options are prefixed with two dashes `--`.

## Q2: What is an advantage of short-form options?

**Correct Option:** you can chain multiple flags together

**Justification:** The lesson mentions that short-form options (single dash) allow you to "chain" multiple flags together, making them more compact for multiple options.

## Q3: How do you pass an optional value with a long-form option?

**Correct Option:** --option=value

**Justification:**  The lesson explains that long-form options use an equal sign `=` to separate the option name from its value.
