# Q1: Which shortcut clears the command line screen?
**Correct Option: Ctrl+L**

*Justification:* Ctrl+L is the standard shortcut to clear the terminal screen in Unix-like operating systems, including Bash.

# Q2: What does Ctrl+Z do in the command line?
**Correct Option: it suspends the current foreground process**

*Justification:* Ctrl+Z sends a SIGTSTP signal, which suspends the current foreground process and stops it from executing further until resumed.

# Q3: How do you rerun the last command in Bash?
**Correct Option: !!**

*Justification:* The '!!' shortcut in Bash represents the last command executed, allowing you to rerun it quickly without retyping.
