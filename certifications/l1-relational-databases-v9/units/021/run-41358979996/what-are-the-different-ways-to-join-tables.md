# Q1: Which SQL JOIN operation returns only the rows where there is a match in both tables based on the join condition?

**Correct Option:** INNER JOIN

**Justification:** The INNER JOIN operation combines records from two tables where there is a match in the specified columns in both tables.

**Evidence:** "INNER JOIN: Returns only the rows that have matching values in both tables."

---

KEY Q1: INNER JOIN

# Q2: Which SQL JOIN operation would you use if you need to retrieve all customers (left) and, for each customer, any orders (right) they might have placed? Customers with no orders should still be included in the result.

**Correct Option:** LEFT JOIN

**Justification:** The LEFT JOIN operation returns all records from the left table and the matched records from the right table. If there is no match, the result will contain NULLs from the right table.

**Evidence:** "LEFT JOIN: Returns all rows from the left table and matching rows from the right table. If there is no match in the right table, the result contains NULLs from the right table."

---

KEY Q2: LEFT JOIN
