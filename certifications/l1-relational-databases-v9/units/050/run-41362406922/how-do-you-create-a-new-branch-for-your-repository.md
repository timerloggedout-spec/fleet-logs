## Answers to FreeCodeCamp Relational Databases v9 Lesson: "How Do You Create a New Branch for Your Repository?"

**KEY Q1:** Make changes without affecting the main branch.

**Q1:** What does creating a new branch in Git allow you to do?

**Correct Option:** Make changes without affecting the main branch.

**Justification:**  Creating a new branch allows you to work on a separate line of development without modifying the main branch.

**Evidence:** *"The purpose of branches is to allow you to work on different features or changes in parallel without affecting the main branch."*

**KEY Q2:** The branch is currently "checked out".

**Q2:** What does the * symbol next to a branch name in git branch output indicate?

**Correct Option:** The branch is currently "checked out".

**Justification:** The lesson explicitly states that the asterisk denotes the currently checked-out branch.

**Evidence:** *"The asterisk (*) next to a branch name indicates that it is the currently checked-out branch."*

**KEY Q3:** Pushes the feature branch and sets it to track the remote branch.

**Q3:** What does the following command do? (git push -u origin feature)

**Correct Option:** Pushes the feature branch and sets it to track the remote branch.

**Justification:** The lesson explains that this command pushes a new branch to the remote repository and sets up tracking.

**Evidence:** *"To push a new branch to the remote repository and set it up to track the remote branch, use the command: `git push -u origin feature_branch_name` "*
