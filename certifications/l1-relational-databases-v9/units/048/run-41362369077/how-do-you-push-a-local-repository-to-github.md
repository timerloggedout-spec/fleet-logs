## Answers to FreeCodeCamp Relational Databases v9 Lesson: "How Do You Push a Local Repository to GitHub?"

**KEY Q1:** git init

**Q1:** What command would you use to initialize a Git repository in an existing local directory?

**Correct Option:** git init

**Justification:**  The lesson states "First, you need to initialize a Git repository in your existing local directory using the `git init` command."

**KEY Q2:** It commits your changes with a short message you provide.

**Q2:** What does the git commit -m command do?

**Correct Option:** It commits your changes with a short message you provide.

**Justification:** The lesson explains "The `git commit -m "your message"` command commits your changes with a short message you provide."

**KEY Q3:** git push

**Q3:** Which of the following commands is used to push up changes to remote repository?

**Correct Option:** git push

**Justification:** The lesson states "To push up your changes to the remote repository, use the `git push` command."
