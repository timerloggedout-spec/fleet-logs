# FreeCodeCamp Relational Databases v9 Lesson: "What Are Primary and Foreign Keys in SQL, and How Do They Work?"

## Q1: What is the primary purpose of a primary key in a relational database table?

**Correct Option:** To uniquely identify each record in the table.

**Justification:** The primary key's main function is to uniquely identify each row or record in a database table, ensuring no duplicate values.

**Evidence from the Lesson:** "A primary key is a column (or combination of columns) that uniquely identifies each row in a table."

---

KEY Q1: To uniquely identify each record in the table.

## Q2: A foreign key in one table typically references which key in another table?

**Correct Option:** A primary key

**Justification:** Foreign keys establish relationships between tables by referencing the primary key of another table, ensuring data integrity and consistency.

**Evidence from the Lesson:** "A foreign key is a column (or combination of columns) in one table that references the primary key in another table."

---

KEY Q2: A primary key

## Q3: Which of the following is a characteristic of a primary key?

**Correct Option:** It must contain unique values.

**Justification:** One of the defining characteristics of a primary key is that it ensures each value is unique, preventing duplicates.
