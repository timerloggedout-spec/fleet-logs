## Answers to FreeCodeCamp Relational Databases v9 Lesson: "How Do You Install and Set Up Git?"

**KEY Q1:** Shows your current setting variables and where they are stored on your system.

**Q1:** What does the following command do? (git config --list --show-origin)

**Correct Option:**  Shows your current setting variables and where they are stored on your system.

**Justification:** This is the explicit function of the `git config --list --show-origin` command as described in the lesson.

**Lesson Evidence:** *"The `git config --list --show-origin` command shows all of your current setting variables and where they are stored on your system."*

**KEY Q2:** The --global flag is used to set the user name for all projects on your system that use Git.

**Q2:** What is the purpose of using the --global flag when configuring your user name?

**Correct Option:** The --global flag is used to set the user name for all projects on your system that use Git.

**Justification:** The lesson explicitly states that the `--global` flag sets a configuration option for all repositories on your system.

**Lesson Evidence:** *"Using the `--global` flag sets this configuration option for all repositories on your system."*

**KEY Q3:** ESLint

**Q3:** Which of the following is NOT a valid option mentioned for setting your preferred editor in Git?

**Correct Option:** ESLint

**Justification:**  The lesson lists Vim, Emacs, and Nano as valid editor options. ESLint is a linting tool, not an editor.

**Lesson Evidence:** *"You can set your preferred editor using the `core.editor` configuration option. Some common choices are Vim, Emacs, and Nano."*
