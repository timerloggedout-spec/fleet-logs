## Answers to FreeCodeCamp Relational Databases v9 Lesson: CI/CD and GitHub Actions

**KEY Q1:** To ensure code changes are tested and integrated frequently.

**Q1: What is the primary goal of Continuous Integration (CI)?**

**Correct Option:**  To ensure code changes are tested and integrated frequently.

**Justification:** This aligns with the definition of CI provided in the lesson: "Continuous Integration (CI) is a software development practice where code changes are frequently tested and integrated into a shared repository."

**Evidence:** *"Continuous Integration (CI) is a software development practice where code changes are frequently tested and integrated into a shared repository."*

**KEY Q2:** The event that triggers the workflow

**Q2: Which of the following is a key component of a GitHub Actions workflow file?**

**Correct Option:** The event that triggers the workflow

**Justification:**  The lesson explicitly states that a workflow file defines "what events trigger the workflow" and "the steps to execute when those events occur."

**Evidence:** *"A workflow file defines what events trigger the workflow and the steps to execute when those events occur."*

**KEY Q3:** To check out the repository's code so the workflow can access it.

**Q3: What is the purpose of the actions/checkout step in a GitHub Actions workflow?**

**Correct Option:** To check out the repository's code so the workflow can access it.

**Justification:** The lesson describes `actions/checkout` as the step "that checks out the code of your repository so that your workflow can access it."

**Evidence:** *"The `actions/checkout` action is a step that checks out the code of your repository so that your workflow can access it."*
