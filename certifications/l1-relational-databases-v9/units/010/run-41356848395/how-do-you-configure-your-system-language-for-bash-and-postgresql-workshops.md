# Answers to FreeCodeCamp Relational Databases v9 Lesson "How Do You Configure Your System Language for Bash and PostgreSQL Workshops?"

## Q1: Why configure the system/keyboard language to an English layout for Bash and PostgreSQL workshops?

**Correct Option:** special characters can behave differently across layouts

**Justification:** The lesson explains that certain characters, like the semicolon (;), are in different positions on non-English keyboard layouts, which can cause issues with workshop checks.

**Evidence:** "...characters whose input depends on the keyboard/system language layout...for example, the semicolon (;) character, which sits in different positions on different layouts..."

## Q2: Which character is used in the lesson body as an example affected by system language/keyboard layout?

**Correct Option:** semicolon (;)

**Justification:** The lesson explicitly states that the semicolon (;) is used as an example of a character that can be affected by the keyboard layout.

**Evidence:** "...for example, the semicolon (;) character, which sits in different positions on different layouts..."
