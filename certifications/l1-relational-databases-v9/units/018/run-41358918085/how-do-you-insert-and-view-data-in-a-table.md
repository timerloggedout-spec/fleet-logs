# Q1: What does the asterisk (*) represent in the SQL statement SELECT * FROM products;?

**Correct Option:** It selects all columns from the products table.

**Justification:** The asterisk (*) in an SQL SELECT statement is a wildcard character that represents all columns in the specified table.

**Evidence:** "The * symbol is a wildcard character that represents all columns in the table."

KEY Q1: It selects all columns from the products table.

# Q2: Which SQL command is used to add a new record to a table named products?

**Correct Option:** INSERT INTO products (name, price) VALUES ('New Product', 4.5);

**Justification:** The INSERT INTO statement is used to add new records to a table, specifying the column names and the values to be inserted.

**Evidence:** "To add a new record to a table, you use the INSERT INTO statement. For example, to add a new product to the products table, you would write something like this:

```sql
INSERT INTO products (name, price) VALUES ('New Product', 4.5);
```

KEY Q2: INSERT INTO products (name, price) VALUES ('New Product', 4.5)
