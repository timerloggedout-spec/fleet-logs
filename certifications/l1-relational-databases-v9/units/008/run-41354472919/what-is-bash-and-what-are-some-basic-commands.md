## Q1: What does the pwd command do in Bash?

**Correct Option:** it prints the working directory

*The `pwd` command in Bash stands for "print working directory," and it displays the full path of the current directory you are in.*

## Q2: Which command creates an empty file named notes.txt?

**Correct Option:** touch notes.txt

*The `touch` command is used to create new, empty files in Bash, so `touch notes.txt` will create a file named "notes.txt".*

## Q3: Which command renames a file in Bash?

**Correct Option:** mv

*The `mv` command in Bash stands for "move" and is used to rename files or directories by moving them to a new name or location.*
