## Notes (summary)
- Download VS Code from the VS Code website — NOT the Visual Studio website (key distinction).
- Windows: .exe installer + setup wizard. Mac: .zip with .app, or Homebrew `brew install --cask visual-studio-code`. Linux: .deb/.rpm; launch via executable or `code` CLI.
