## Notes (summary)
- Code editor = app for editing code files (text-focused; syntax highlighting, folding, extensions/plugins).
- IDE = full environment: edit + compile + run + debug in one application.
- IDE examples: Visual Studio (Microsoft, cross-platform suite), Xcode (Apple platforms), Android Studio (Google, Android).
- Editor examples: VS Code (lightweight, open-source, extensible), Sublime Text, Notepad++ (Windows).
- Cloud editors (browser, no local install): Replit, GitHub Codespaces, StackBlitz. VS Code is NOT in the lesson's cloud list.
- Choice of tool is project-dependent: some tools are tailored to specific languages/project types; extensible tools (VS Code) fit many.

## Exam-domain map (this unit)
- editor-vs-IDE distinction (compile/run/debug = IDE)
- local vs cloud-based editors; example classification
- tool selection rationale (language/project fit)
